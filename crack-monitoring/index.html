Crack Monitoring System — Real-Time Multi-Camera Deployment

Sanlien Technology Corp. · Sole developer · September 2025 – January 2026

  • Translated field monitoring requirements into a standalone multi-camera crack-monitoring system supporting concurrent RTSP streams, segmentation, identification, and automated crack measurement.
  • Implemented automatic physical-scale calibration and seismic-event re-calibration, converting pixel-level crack masks into physical length and width measurements despite camera and target movement.
  • Integrated socket-triggered seismic event recording, automatically archiving 30 s before and 60 s after each event with synchronized images, measurements, timestamps, and camera identifiers.
  • Designed and packaged the client-ready Windows application, including system-status, multi-camera, and detailed inspection views, with no additional environment configuration required.
