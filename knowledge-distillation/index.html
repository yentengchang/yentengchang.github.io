Cross-Architecture Knowledge Distillation for On-Device Defect Detection

Master's thesis research, National Taiwan University · 2024–2026

  • Identified the architecture dependence of conventional distillation and designed an architecture-agnostic dual-path framework using detection-head alignment and cross-architecture pseudo-label supervision.
  • Implemented the framework through direct YOLO11 source-code modification, combining YOLO11-L and RT-DETR-L teachers with mask-based foreground weighting while preserving the 2.6 M-parameter YOLO11n student.
  • Improved mAP50-95 by +0.026, versus +0.008 for the architecture-matched baseline; evaluated distillation strength, foreground weighting, and teacher architectures through controlled experiments.
  • Validated knowledge-transfer effects using five-seed statistical tests and shuffled-teacher controls, then deployed the student via Core ML at ~430 FPS on Apple M2 with no added inference cost.
